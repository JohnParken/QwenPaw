# PPTX

Inspect and create PowerPoint Open XML presentations. Prefer stable typed
presentation operations, keep slide order and speaker notes intentional, and
validate the package before publishing. Visual acceptance requires a separate
renderer and must not be inferred from XML inspection.

本政策的权威原生来源是 `src/qwenpaw/agents/skills/pptx-zh/SKILL.md`；运行
目录、脚本与完整操作说明均以该原生来源为准。
